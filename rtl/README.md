# Synthesizable computer hardware

`jmr_js_core.sv` joins the JS machine, console, disk, graphics and shared desktop.
`top_nexys_video.sv` connects it to Nexys Video DDR3, HDMI, SD, and audio.
Default jacks: USB keyboard on J15, PS/2 mouse on JA, second PS/2 mouse on JC, joystick on JB.
`engines/` contains the machine engines; `video/` the display; `phys/` the physical links.

The classic UI uses `jmr_classic_ui`, `jmr_system_menu`, `jmr_system_documents`,
`jmr_system_actions` and `jmr_classic_overlay`. `jmr_ui_snapshot` transfers coherent
UI state to the display clock. UI text/catalog RAM is separate from the one JS heap.
`jmr_classic_ui_pkg.sv` is generated by `tools/export_classic_ui.py`.

Verilator and Vivado build this same RTL. Use `make -C sim sim_server_synth` to
check it before making hardware. Board build instructions are in `tools/board_flow/`;
that build must pass fit, route, timing and DRC checks before a bit is released.
Application menu examples and agent instructions: `docs/SYSTEM_APPLICATIONS.md`.
